# Rigged horse credit

`Horse.glb` (the source for the baked atlases in `src/game/rigged/`) is from the
"Ultimate Animated Animals" pack by Quaternius, released under CC0 1.0
(public domain): https://quaternius.com

The model has been re-rendered offline with the game's lighting and 7 view angles,
then combined with a custom-built, original rider. The shipped game loads only the
resulting sprite atlases; no Three.js or GLB is included in the web bundle.

The rider, saddle, cloak, emblem, and seating rig are original work for this project.
